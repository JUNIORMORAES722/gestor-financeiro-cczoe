# Gestor Financeiro - CCZoe

Sistema de gestão financeira para controle de fluxo de caixa, tesouraria e relatórios. Desenvolvido para atender demanda real de uma igreja, com arquitetura escalável para pequenos negócios e ONGs.

### 🚀 Funcionalidades
- Cadastro de entradas e saídas por categorias (dízimos, ofertas, despesas)
- Dashboard com saldo em tempo real
- Relatórios financeiros mensais
- Controle de responsáveis por movimentação
- Backup automático com banco em nuvem

### 🛠️ Tecnologias
- Front-end: HTML5, CSS3, JavaScript
- Back-end: Node.js, Express
- Banco de Dados: PostgreSQL (Neon)
- Segurança: Helmet, Express Rate Limit
- Hospedagem: Vercel / Render
